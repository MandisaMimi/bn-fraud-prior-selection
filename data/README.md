# Data
The real-data experiment uses the public ULB credit-card fraud dataset (284,807 transactions, 492 fraud),
released with Dal Pozzolo et al. (2015). It is about 100 MB and is not stored in this repository.
Download `creditcard.csv` and place it in this folder (it is git-ignored), then run:

    python code/realdata.py data/creditcard.csv code/outputs/real_results.csv 30

All synthetic data are generated by the code from fixed random seeds (42-61); no data files are required for them.
